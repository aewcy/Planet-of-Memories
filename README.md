# 记忆星球 · Planet of Memories

一片属于朋友与彼此的深空记忆星空。每张照片都会化作一颗发光的星辰，围绕中心主星旋转或在外环深空漂流；点开星辰，AI「记录者」会陪你聊聊画面里的故事，并将这一刻封存成拍立得批注。

- **双层星空**：支持个人私密星空与多人邀请制星系，中心主星可绑定照片与纪念日
- **轨道与漂流**：上传照片可自由选择在星系内旋转，或在外环深空随视角缓慢漂流
- **拍立得与 AI 记录者**：支持堆叠浏览、多模态识图对话与「封存这一刻」批注生成
- **全端适配**：桌面端鼠标视差与引力光标，移动端拖拽视角、长按菜单与手势滑动
